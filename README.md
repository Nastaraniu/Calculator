# 🧮  Calculator

A simple command-line calculator built with Python. It performs five basic mathematical operations and allows users to perform multiple calculations.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ^ Exponentiation 
- 🔁 Repeat calculations without restarting the program

## 🛠️ Built With

- Python

## 🚀 How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the Python file:

   ```bash
   python calculator.py
   ```
